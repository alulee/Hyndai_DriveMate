# DriveMate — AI 초보운전 동승 코치 (체험 데모)

PLEOS CONNECT 앱 콘셉트 공모전 제출물의 인터랙티브 데모입니다.
기획서 7~14페이지의 8개 기능을 **PPT 원본 화면 기반 영상 + 한국어 음성**으로 체험할 수 있습니다.

## 실행 방법
1. GitHub Pages 배포 링크로 접속 (아래 참고) — 또는 `index.html`을 크롬·엣지에서 열기
2. 메인 화면에서 **연수 시작** 클릭
3. 기능 카드를 클릭하면 영상과 한국어 코치 음성이 자동 재생됩니다

## 구성
| 기능 | 시연 방식 |
|---|---|
| 경로 예습 · 주행 코칭 · 차선 변경 · 교차로·회전 · 고속도로 합류 | 15초 영상 |
| 좁은 골목 · 주차 학습 · 연수 리포트 | 6초 영상 |

- 영상·이미지: 기획서 PPT 원본 화면 기반 생성
- 음성: 한국어 여성 코치 내레이션 (영상 내장)
- 별도 서버·API 없음 (단일 HTML, 음성·영상 내장)

## 주의
실제 차량 연결이 없는 시연용 데모입니다. 주행 중 사용 금지.
