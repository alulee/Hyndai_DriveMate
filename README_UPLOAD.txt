[업로드 순서 — 5분]
1. https://github.com/alulee/Hyndai_DriveMate 접속
2. "Add file → Upload files" (또는 code 화면에서 drag & drop)
3. 이 zip 안의 내용물(README.md, index.html, videos/ 폴더)을 그대로 올리고 Commit
   ※ zip을 통째로 올리지 말고, 압축을 풀어 내용물을 올려주세요
4. Settings → General 맨 아래 Danger Zone → "Change visibility" → Public 선택
5. Settings → Pages → Branch: main / (root) 선택 → Save
6. 1~2분 후 https://alulee.github.io/Hyndai_DriveMate/ 접속 확인
   - 공개 전환 전에는 이 링크가 외부에서 열리지 않습니다 (GitHub 정책)
   - 유료 플랜이 아니라면 비공개 저장소는 Pages 자체가 불가합니다
